# 健康记录 (Health Record)

记录睡眠与自定义习惯的自用 Obsidian 插件：出厂只有睡眠和水，三餐、如厕、运动这些自己加。侧边栏一键记录，周/月回看，数据是库里的 Markdown。

## 📥 下载安装（小白版）

1. 到本仓库的 [Releases](../../releases/latest) 页面，下载最新的 `health-record-<版本号>.zip`。
2. 解压，得到一个 `health-record` 文件夹。
3. 打开你的笔记库文件夹，进入隐藏目录 `.obsidian/plugins/`（没见过这个目录的话：在 Obsidian 里点左下角仓库图标 →「在系统资源管理器中显示仓库」，进去就能看到 `.obsidian`）。
4. 把解压出的 `health-record` 文件夹整个放进去，变成这样：

```
你的笔记库/
└── .obsidian/
    └── plugins/
        └── health-record/
            ├── main.js
            ├── manifest.json
            ├── styles.css
            └── versions.json
```

5. 重启 Obsidian → 设置 → 第三方插件 → 关闭「安全模式」→ 在已安装插件列表里启用「健康记录」。
6. 手机端：把整个笔记库同步过去即可，插件本身支持移动端。

## 功能特性

- **一键记录**：水、如厕这类真计数的，点一下就写入当前时刻，不弹窗、不填表
- **想让它问一句吃了什么**：番茄鸡蛋面、外面吃的、聚餐——只留一个 +1 数字等于什么都没记。新建的类型默认只计数，在「管理类型」里点它的名字展开、按「问内容」切换；切完之后点它就是弹一个框，时间已经填好、光标停在内容上，写完回车就走
- **类型是一张自己的清单**：在侧边栏「管理类型」里新建（运动、吃药、读书…）、换图标、换颜色、关掉显示、删除。上限 16 个（含睡眠），满了会直接告诉你加不进去。只有睡眠删不掉——它是唯一记两个时刻的类型
- **睡眠一条记完**：睡前不用点。醒来点「我醒了」，起床取现在、入睡照上一晚填好，不准就在弹窗里改；夜里真躺下了想记一笔，用命令面板的「记录入睡」（凌晨那一记会自动算到前一晚）。一晚只记一觉，分段（醒了又睡）没建模，写在当天的引用块里更清楚
- **撤销上一条**：手滑多点了一次，直接撤销，不用去列表里找。录完一笔后「快速记录」标题旁会亮出一枚「撤销」（只管刚记的那条，没有可撤的就不占地方），手机上不用翻命令面板
- **侧边栏视图**：固定在右侧栏，和「月历任务」「重要日子」「闪念笔记」并排切换，不占主编辑区
- **一页装到底，不上下滚**：头部 + 一个撑满剩余高度的面板 + 底部一条切换钮。今日分「记录 / 明细」，本周分「睡眠 / 次数 / 计数 / 缺口」，本月分「睡眠 / 次数 / 最短」。以前这些卡片叠在一列里往下堆，复盘要看的东西永远在折叠线以下；现在图拿到了整页高度，一周七行一行五六十像素，终于看得清
- **昨今同刻对比**：今日「明细」页顶部的总览条里，每个数字旁的小差值比的是昨天同一时刻——下午三点打开，只和昨天下午三点前比，今天还没过完也不吃亏；昨天没记写「昨日未记」，不硬比。↑↓ 只报方向，不上红绿褒贬。睡眠那枚和前一晚比时长，差值换睡眠色相——计数归紫、睡眠归蓝紫，颜色即语义；刚开始记、还没有可比的昨天时，这里是一行引导而不是整排灰字
- **周/月环比**：周/月页统计条的每个数字下缀一行小差值，比上一窗口——动态窗口比前 7/前 30 天；日历周/月比上周/上月的同进度段（周一打开只和上周一比，不吃月初长月末短的亏）
- **计数矩阵带热力底**：周页「计数」面板的格子铺一层自己色相的底色，深浅按当天次数分档（每列以最大值为满档），哪天记得密一眼看出；没记的格子保持透明，不把「没记」染成「记了但少」
- **快记角标与轻脉冲**：快记格子右上角标出今天已记次数，色深之外补一个精确读数；点成功闪一下轻脉冲，「问内容」型弹窗不闪
- **今日页箭头切日**：日期标题两侧的 ‹ › 翻前一天/后一天，翻到今天时右箭头自动失效（未来的日子不列），翻远了旁边就是「返回今天」。特意不用滑动手势——那和 Obsidian 移动端的边缘滑动返回是同一个动作，会互相打架
- **日间夜里说同一种话，只是方向相反**：卡面走主题的 secondary 档（日间是比页面暗一点的灰，夜里是比页面亮一点的灰），卡片再套一圈 1px 内描边；描边、填充面、输入框那口「井」一律用带透明度的淡墨（日间）/ 淡白（夜里），不拿 `color-mix` 去混主题色——压在什么卡面上都是重一档，也不看浏览器脸色。快记每一格都带自己那一点色相，记过之后同一枚圆底加厚、再套一圈同色环
- **管理类型是一行一个、点开才铺控件**：收起时一行只写"水 · 水蓝"，跟默认不一样的地方才写（"已隐藏""记时问内容"），不写"显示中 · 只计数"这种废话占位。点开才有图标格与颜色点。图标是一排真图标，不是一排 `droplet`、`utensils` 这种英文名。关掉的类型不进快记网格、不进计数表、也不进补记弹窗的类型列表
- **睡眠看横条**：一天一行，一根条从入睡拉到起床，右边写着 `22:24 → 03:36`。时长不适合折线——23:40 睡和 01:30 睡可以是同一个「7 小时」，折线把这个区别抹平了，而要看恰恰是这个区别。轴跟着这几晚走，深浅就是睡了多久；起床还空着的那晚画成虚条，一直虚到轴头
- **次数看折线**：记录条数、以及每个自建类型各自的次数。横轴是日期，**没记录的那天空着，不连成 0**——"这周有三天没记"和"那三天都是零"是两回事
- **未来的日子不列**：窗口只到今天，不然每月中旬看趋势都是"后半截全空"，分母也跟着虚
- **默认只有睡眠和水两种类型**：其余（三餐、如厕、运动、吃药…）自己在「管理类型」里加。插件不该替你决定要记什么
- **数据是你的**：全部写在笔记库里的 Markdown 文件，可以直接手工编辑，也能被其它插件读取

## 数据文件

默认写在 `健康记录/2026-10月健康记录.md`，按日期分区。归档方式在设置里选：**按月**一个文件（`2026-10月健康记录.md`）或**按年**一个文件（`2026年健康记录.md`）。

```markdown
# 健康记录

> 格式：一天一节，节标题是 `## YYYY-MM-DD 周几`；节里一行一条记录，写成 `- 类型 | 时间 | 备注`。
> 睡眠的第三列是**起床时间**，不是备注；而且整条记在**入睡那晚**——`10-18` 下面的 `睡眠 | 23:40 | 07:10` 是 18 日深夜睡下、19 日早上起床。
> 其余类型的第三列是内容或备注。插件认不出的行一律原样保留、不参与改写。
> 想给某一天多写几句，用 `>` 引用块或普通段落：插件不读它、不显示它，新记录一律排在它下面，不会把那段话挪走。

## 2026-10-18 周日

- 睡眠 | 23:40 | 07:10
- 早餐 | 08:05
- 水 | 08:20
- 水 | 09:30
- 如厕 | 09:35
- 午餐 | 12:30 | 食堂

> 今天状态一般，午饭后有点困。中午在外面吃的。
```

几点约定：

- **一天里想写大段话，用 `>` 引用块（或普通段落），也可以直接写你自己的清单行**：插件只认形如 `- 类型 | 时间 | ...` 的记录行——引用块里的、代码块里的、没有竖线的清单行（`- 备注：记得复查血压`）都不读、不显示、不计条数。**规矩是"你的话在文件里的位置一动不动"**：插件把你在这节里写的最后一段正文当成一道界，新记录只排在这道界**以下**，界以上一概不动。所以话写在记录上面 → 记录在下面接着排；话写在记录下面 → 记录长到你那句话的底下去。界以下仍按时刻排序，你那一段话永远不会被顶下一行、也不会被楔成两段；那一天还没有记录时，新记录落在你那段话底下，紧贴着写、不额外空一行。明细行右边的「定位」键直接跳到原文那一行，方便你在下面接着写。

- **睡眠锚定「入睡那晚」**：10-18 下面的 `23:40 | 07:10` 是 18 日晚上睡、19 日早上起。这样"昨晚睡了多久"永远在昨天那一格，不会每天差一天。
- **起床没记时第三列留空**：`- 睡眠 | 23:40 |`，第二天早上点「记录起床」会自动补在同一行。
- **第三列的含义按类型分**：睡眠行是起床时刻，其它行是备注。
- **类型名就是行首那一列**：自建类型只能删不能改名，改名等于换了一个类型，老数据还在文件里但不再被读出来。要换名请删掉再加，或者手工把老行一起改掉。
- **一天之内的行按时刻排好序插入**，不是无脑追加到分区末尾：手工翻看时顺序是顺的
- **新建的文件自带上面那段格式说明**（只写一次，反复写不叠加），日期标题带星期。这份文件离开插件也读得懂：整份丢给 AI、或者半年后的自己打开，不用查文档就知道每一列是什么、睡眠为什么挂在昨天
- **手工加的、类型还不认识的行不会被悄悄吞掉**：文件里出现 `- 奶茶 | 16:40 | 珍珠` 而清单里没有"奶茶"时，明细照样列出这一行并标"类型未注册"，本周的「缺口」面板也会报"N 行类型不在清单里，没计入统计"。它不进条数——要进统计，去「管理类型」加一个同名类型就行
- **插件认不出的行一律不动**：你自己在文件里写的清单、待办、四列以上的行，会被原样保留，不会被改写时抹掉。
- **你在文件里改，插件跟着变**：手工增删记录行、甚至把整个文件删掉，侧边栏的读数和设置页那份目录列表都会当场刷新（靠 Obsidian 的文件事件，不是等几秒再看一眼）
- **读哪个文件认内容，不认文件名**：`2026-10.md`、`2026-10-备份.md`、`2026年健康记录.md` 都算，只要里面有日期分区和记录行。所以改了归档方式、给文件改名，老数据不会从界面上消失。注意只认**你选定的那个目录**里的文件：挪到别的文件夹或子目录里，就得回设置页重新扫描点选。
- **切换归档方式不动老文件**：只决定以后往哪个文件下笔。已经有某一天记录的文件会一直被用它，同一天不会被劈成两半。
- **同一天的同一行在两处出现只算一次**：同步盘产生的冲突副本不会让记录数翻倍；真按了两次的两条（同一文件里的重复行）照样都留着。

## 使用

- 点左侧竖栏的活动图标打开侧边栏，或用命令面板「打开健康记录」。
- 顶部三个标签：**今日**（记录 / 明细——昨今对比总览条在明细页顶部；日期两侧的箭头翻前一天/后一天）、**近 7 天**（睡眠 / 次数 / 计数 / 缺口）、**近 30 天**（睡眠 / 次数 / 最短）。周/月页底部那条按钮换面板，整页不上下滚，复盘那一屏的行高按面板高度平分；只有明细那种长列表在面板内部滚。近 30 天倒着排，刚记的那一晚在顶上。明细按时段（凌晨／上午／下午／晚上）分组，长长一根列表里好定位；手机上统计条排两行两列，数值不挤。
- 复盘范围在设置里可换：**动态**（默认）是近 7 天、近 30 天，窗口永远以今天收尾——周一打开也是完整一周，昨天那觉不会掉出"本周"；**按日历**是本周（周一到周日）与本月（1 号到今天），跟日历对得上，代价是周一那一格几乎空着。标签页的名字跟着这个选择变（近 7 天 / 本周）。
- 「睡眠」面板是横条，点某一行直接改那一晚的入睡/起床（没记的那行点进去就是补记）；「次数」面板是折线，右上角的芯片换看哪个类型，点线上的点会跳到那一天的明细页。
- 点明细行右侧的笔可以改时间、加备注；垃圾桶要点两下才删（第一下会染红）；最左边那个箭头打开记录文件并把光标停在这一行——想接着写一大段，就在下面开个引用块。
- 补记过去的记录：点标题右侧的笔形图标，日期点日历按钮选（带今天/昨天/前天快捷项，也可以手打），时刻字段右侧各有一枚时钟键，点开是时、分两列可上下拨的轮子，也可以手打。
- 睡眠那条挂在**入睡那晚**：早上补记时日期填昨天。选时刻会自动带日期——凌晨（12 点前）一律归前一晚，晚上还没到的钟点归昨晚；下午的时刻和你已经手改过的日期不动。
- 命令面板里一共十三条：打开健康记录、记一杯水、记一次如厕、记早餐、记午餐、记晚餐、记加餐、记录入睡、记录起床、记昨晚的睡眠（补记）、撤销上一条记录、补记一条、打开当前记录文件。其中后五个和"打开"一直在；那六个按类型的（水、如厕、三餐、加餐）**只在同名类型还在清单里时出现**，删掉类型后命令要到下次启动才消失（Obsidian 没有卸载命令的 API）。其余自建的名字没有命令，从侧边栏网格或补记弹窗里记。
- 想加自己的类型：侧边栏 → 今日 → 「快速记录」标题右边的「管理类型」，起名即建，图标、颜色、是否显示、是否问内容都在这一处改；改完记得这个清单就是全部生效类型，删掉某项后它在文件里的老行不再被统计（但原样留着）。没有"恢复默认清单"那种一键操作——不记了的类型你自己删。
- 记录文件放哪儿不用设：设置页打开就自动扫，扫出来只有一处就直接定位，好几处才列出来让你点。
- 归档粒度在设置里换：按月一个文件 / 按年一个文件。切换只影响以后往哪个文件下笔，老文件原样留着、照样读得出来。
- 「打开时停在哪个标签页」「复盘看哪个指标」不设默认值：上次关在哪儿，下次就在那儿。
- 删除自建类型要点两次确认：删掉之后文件里那些行会原样留着，但不再被读出来统计。

## 兼容性

- 桌面端与移动端均可用（`isDesktopOnly: false`）。
- 窄侧边栏（<400px，手机全屏抽屉约 390px）自动切换成紧凑排布：两列快记、精简头部。
- 深色/浅色模式跟随 Obsidian 主题，配色只用主题变量，不锁死背景色。
- 需要 Obsidian 1.4.0 及以上（低于这个版本 Obsidian 不会加载本插件）。写入走 `vault.process` 原子读改写；万一某个版本没有这个接口，代码会回落到读-改-写，那时双端同时记录才可能互相覆盖。

## 已知边界

- 不做提醒、不做目标值。Obsidian 本身弹不出系统通知，"每天 8 杯水"这类阈值只会把一个记录工具变成又一个完不成的清单。
- 「撤销上一条」只覆盖这一次会话里最后一次一键记录或「记录入睡」；起床、补记、修改、删除都不进撤销栈（它们本来就有原地的修改和删除入口）。
- 睡眠只记"一晚一觉"，午睡/分段睡眠没有建模：横条一天只画一条（取入睡最晚的那条），一个文件里同一晚记了两觉，图上只看得到一条。
- 横条的轴跟着这几晚自动收放（最短 9 小时，最长一整天）：傍晚一觉和深夜一觉记在同一周里，轴会摊到 24 小时，条就偏细。条永远画在轴内，不会有哪一晚被甩出去。
- 存储目录里请只放插件自己写的那些文件。手工留一份 `2026-10月备份.md` 之类"内容也像记录"的副本，这一天的记录会被算成同一份（去重），而新的一笔下笔时可能落到那份备份里去。同步盘自己产生的冲突副本（`… 1.md`）已经认不出来了，不用管。
- 自建类型都是计数型（一次一条 + 一个时刻），表达不了"从几点到几点"，那种结构是睡眠专属的。
- 修改记录不能换日期，需要换日期请先删除再补记。
- 未来的日子记不了：日历里点不动，手打日期也会被拒。因为本周/本月都只列到今天，写进去的记录在界面上永远看不见，不如不写。
- 代价说清楚：**只要你在当天的记录底下写过话，这一天的记录在文件里就会分成两拨**（你那句话上面一拨、下面一拨），补记一条更早的时刻也会排到下面那一拨的末尾，不再越过你的话插回上面。文件看着是两截，**界面上不是**——明细按时刻排，那条 07:00 照样排在当天最前面，条数、图表、缺口都不受影响。要恢复成一整截，就把那句话挪到当天记录的上面。
