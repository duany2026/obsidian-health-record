# 健康记录 (Health Record)

记录睡眠与自定义习惯的 Obsidian 插件：侧边栏一键记录，按日、周、月回看。数据全部写在库内的 Markdown 文件里，可以直接手工编辑，也能被其它插件读取。

安装：Obsidian 设置 → 第三方插件 → 浏览，搜「Health Record」→ 安装启用。手动安装方式见[文末](#安装)。

## Health Record

An Obsidian plugin for logging sleep and custom habits from a sidebar view, with day / week / month reviews. All data is plain Markdown in the vault — no network access, no account.

- **UI languages**: follows Obsidian's language — Simplified Chinese, Traditional Chinese, or English; anything else falls back to English. No separate setting.
- **Data files**: new files are written in your interface language (`Health Records/Health Records 2026-10.md`, `# Health Records`, `## 2026-10-18 Sun`, `- Sleep | 23:40 | 07:10`); files in any of the three languages are always read, and records added to an existing file keep that file's language. Switching language never renames, rewrites or splits files.
- **Usage**: ribbon icon or "Open health record" command → sidebar with Today / 7 days / 30 days tabs. One-tap counters, "I woke up" sleep logging, per-type commands, undo for the last quick record.
- **Compatibility**: Obsidian `>= 1.11.0`, desktop and mobile. MIT license — see [LICENSE](./LICENSE).

## 功能特性

- **快速记录** — 水、如厕等计数类型点一下即写入当前时刻；「问内容」的类型点开弹框填备注
- **睡眠记录** —「我醒了」一次记完入睡与起床；凌晨那一记自动归到前一晚
- **复盘** — 睡眠看横条（入睡→起床），次数看折线，计数看深浅底色矩阵；周 / 月数字与上一窗口同进度段对比
- **类型清单** — 默认只有睡眠和水，其余自己在「管理类型」里添加（最多 16 项）
- **明细** — 按时段分组，可改时间、加备注、删除、定位到原文
- **撤销** — 刚记完一笔后出现「撤销」，覆盖本次会话最后一次一键记录
- **简体 / 繁体 / English** — 界面跟随 Obsidian 语言设置；其他语言显示英文
- **离线** — 不联网、无账号；记录全在库内 Markdown 文件

## 使用方法

点活动栏图标或运行命令「打开健康记录」打开右侧栏。顶部三个标签：**今日**（记录 / 明细）、**近 7 天**、**近 30 天**；复盘范围可在设置里改为按日历的本周 / 本月。

- 快速记录：点类型按钮写入当前时刻；睡眠用「我醒了」一次记完，入睡时间预填自前一晚
- 明细：日期标题两侧的箭头翻看过去的日子，未来日期不可选
- 命令面板提供十三条命令（打开、按类型的快记、记录入睡 / 起床、补记、撤销、打开记录文件）；按类型的命令只在同名类型存在时注册

## 数据文件

默认写在 `健康记录/2026-10月健康记录.md`；归档周期可在设置里改为按年（`2026年健康记录.md`）。切换只影响以后下笔的文件，已有记录仍从原文件读取。

**三种语言的写法都认。** 新建文件按当前界面语言写；往已有文件里加记录时沿用这份文件自己的语言，同一份文件不会中英混排。切换 Obsidian 语言后，老文件照常读写，不改名、不重写、也不会因为换了语言另起一份同月的新文件。自己改过的目录和文件名保持不变。

| | 简体中文 | 繁體中文 | English |
| --- | --- | --- | --- |
| 默认目录 | `健康记录` | `健康記錄` | `Health Records` |
| 按月文件 | `2026-10月健康记录.md` | `2026-10月健康記錄.md` | `Health Records 2026-10.md` |
| 按年文件 | `2026年健康记录.md` | `2026年健康記錄.md` | `Health Records 2026.md` |
| 文件标题 | `# 健康记录` | `# 健康記錄` | `# Health Records` |
| 日期分区 | `## 2026-10-18 周日` | `## 2026-10-18 週日` | `## 2026-10-18 Sun` |
| 内置类型 | 睡眠 / 水 / 如厕 / 早餐 / 午餐 / 晚餐 / 加餐 | 睡眠 / 水 / 如廁 / 早餐 / 午餐 / 晚餐 / 加餐 | Sleep / Water / Toilet / Breakfast / Lunch / Dinner / Snack |

自建类型的名字原样写入，不翻译。

```markdown
# 健康记录

> 格式：一天一节，节标题是 `## YYYY-MM-DD 周几`；节里一行一条记录，写成 `- 类型 | 时间 | 备注`。

## 2026-10-18 周日

- 睡眠 | 23:40 | 07:10
- 水 | 08:20
- 午餐 | 12:30 | 食堂

> 今天状态一般，午饭后有点困。
```

- 一天一节，一行一条，格式 `- 类型 | 时间 | 备注`。睡眠的第三列是**起床时间**，且整条记在**入睡那晚**；未记起床时第三列留空
- 类型名就是行首那一列。删除类型后历史行原样保留但不再计入统计；类型不能改名，改名等于换了一个类型
- 引用块、普通段落、待办清单、四列以上的行都属于你自己写的内容：插件不读取、不显示、不改写，新记录一律排在你最后一段正文之后。界以下仍按时刻排序
- 文件顶部自带一段格式说明（只写一次），日期标题带星期；这份文件离开插件也能读懂
- 认内容不认文件名：`2026-10.md`、手工改名的备份都算，只要里面有日期分区和记录行。**只认选定目录里的文件**，挪到别处需在设置里重新扫描
- 同一天的同一行出现在多份文件里只算一次（同步盘冲突副本）；同一文件里真记了两次的两行会分别保留
- 在 Obsidian 内修改记录文件，或改动经同步盘落地后，侧边栏会在短暂延迟内更新；`data.json` 只存设置偏好，不存记录

## 设置项

设置页分「显示」「归档与位置」两区：归档周期（按月 / 按年）、复盘范围（动态近 7 / 30 天或按日历）、记录文件目录（打开时自动扫描）、类型清单与图标颜色。上次停在哪个标签页、看哪个面板会被记住，不作为设置项。

## 记录对不上时

1. 到「今日 → 明细」用行首箭头定位原文，确认那一行是否符合 `- 类型 | 时间` 格式
2. 检查「管理类型」里是否还保留该类型；未注册的行会照常列出，但不计入条数
3. 检查默认排除项：排版符号、网址与邮箱、插入内容、代码与注释、笔记开头的属性区、附件，以及带 `#exclude-from-word-count` 标签或 `wordcount: false` 的笔记
4. 在 Obsidian 之外改动过文件时，重新打开一次插件视图

## 已知边界

- 不做提醒与目标值；睡眠只记一晚一觉，午睡与分段睡眠没有建模
- 自建类型都是计数型，表达不了「从几点到几点」；修改记录不能换日期，需删除后补记
- 当天记录底下写过话时，文件里会分成两拨；界面上仍按时刻排，条数与图表不受影响
- 存储目录里请只放插件自己写的记录文件。手工留下内容相似的副本时，新记录可能落到副本里；同步盘产生的 `… 1.md` 冲突副本已被排除
- 用 OneDrive / iCloud 同步整个库时，`data.json` 也会同步；两台设备同时打开同一库可能各自多统计一次，但不丢记录

## 安装

**社区市场（推荐）**：Obsidian 设置 → 第三方插件 → 浏览 → 搜「Health Record」→ 安装启用。

**手动安装**：从 [Releases](../../releases/latest) 下载 ZIP，把解压出的 `health-record` 文件夹放进 `<库>/.obsidian/plugins/`，重启 Obsidian 后启用。也可直接放置 `main.js`、`manifest.json`、`styles.css` 三个文件。

需要 **Obsidian 1.11.0 或更高**，桌面端与移动端均可用。

- 新增：界面跟随 Obsidian 语言设置显示简体中文、繁體中文或 English，不用另外设置；其它语言的 Obsidian 显示英文
- 新增：记录文件三种语言的写法都能读；新文件按界面语言写，往老文件里追加时沿用那份文件原来的语言

- 改进：「补记一条」弹窗的时间占位符改为 `HH:MM` 格式提示，不再像已填好的值

- 内部：回归测试增加到 57 项，覆盖三语读写和跨语言追加

### 0.8.3（2026-11-17）

问题修复。**界面和操作方式都没有变化**。
